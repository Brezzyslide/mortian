# Rider app (Phase 2)

React Native + Expo, Android first; iOS from the same code when switched on. Built with EAS Build (iOS builds cannot run on Linux CI).

Planned scope: phone + OTP login, financing status, job offers and acceptance, pickup/delivery OTP and photo proof, background location during active jobs, earnings view, offline queue for status updates.

Scaffolded in Phase 2 with `create-expo-app` so it tracks the current Expo SDK at that time rather than one pinned today.
